# ⚡ Fast Crypto Whale Radar (Open Source Edition)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)

[![Stars](https://img.shields.io/github/stars/HaiNam1710/fast-crypto-whale-radar?style=social)](https://github.com/HaiNam1710/fast-crypto-whale-radar)

Lightweight, zero-bloat on-chain whale tracker monitoring high-volume transactions across Binance Smart Chain (BSC) and Ethereum in real time.

---

## 🚀 Key Features
- **Async Polling:** Millisecond-level block parsing via public RPCs.
- **Discord / Telegram Webhooks:** Instant alerts formatted with rich embeds.
- **Zero Config:** Runs out of the box with zero external dependencies.

## 💻 Quick Start
```bash
git clone https://github.com/HaiNam1710/fast-crypto-whale-radar.git
cd fast-crypto-whale-radar
python radar.py --min-usd 100000
```
